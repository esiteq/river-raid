Браузерний ремейк культової аркади **River Raid** (Activision, 1982) —
керуєш літаком, летиш над річкою, збиваєш ворогів, підриваєш мости,
стежиш за пальним і не влітаєш у береги.

> Це фан-проєкт для навчання/експерименту, не пов'язаний з Activision і
> не має комерційної мети.

## Про проєкт

Ця гра — експеримент: наскільки швидко і наскільки грабельно (playable!)
можна зробити повноцінну аркадну гру, попросивши про це Claude. На базову
версію гри (терейн, що скролиться, керування літаком, вороги, паливо,
рахунок, мости) і кілька раундів доопрацювань та фіч поверх оригіналу
пішло приблизно **3 години** — від першого запиту "зроби браузерну версію
River Raid" до фінальної версії з усім переліченим нижче.

Увесь код, спрайти й звуки згенеровані — жодного зовнішнього арту чи
аудіофайлів, усе намальовано і синтезовано програмно.

## Керування

| Клавіша | Дія |
|---|---|
| `←` `→` | рух літака вліво/вправо (з нахилом "на крило") |
| `↑` | газ (пришвидшення) |
| `↓` | гальмо (майже до зупинки — потрібно для заправки) |
| `SPACE` | постріл / старт гри / рестарт після програшу |
| `P` / `ESC` | пауза |

## Функціонал

Базова механіка: рельєф річки, що процедурно генерується і плавно
(не рвано) вигинається; острови; паливо, що витрачається залежно від
швидкості; три життя; рахунок очок; мости, які можна підривати пострілом.

Вороги: гелікоптери, кораблі та швидкі реактивні літаки (не стріляють,
летять горизонтально) — не більше трьох одиниць кожного типу одночасно
на екрані, щоб не рябіло. Берегові танки заїжджають до берега саме з
того краю екрана, де їхній берег, і стріляють лише припарковані біля
води; постріли завжди строго горизонтальні, без прицілювання по гравцю.
Якщо на шляху танка стоїть дерево — він упирається в нього і назавжди
застрягає, не доїжджаючи й не стріляючи.

Мости: якщо знищити міст разом із танком, який саме переїжджає по
ньому — рахунок потроюється (у танка є "втеча", тож треба встигнути).

Бонуси — веселкові повітряні кульки з літерою, яка позначає ефект:
`T` потрійний вогонь (вперед + вліво + вправо), `M` дві ракети з
самонаведенням (додатково до звичайного пострілу), `D` подвоєна частота
стрільби, `F` миттєва заправка на 100%, `N` знищує всіх ворогів на
екрані (кульки не займає), `X` додаткове життя. Активний бонус тримається
до підбору іншого або до втрати життя; спецпостріли (ракети,
бічні постріли) ігнорують кульки — збити їх можна лише звичайним
пострілом вперед.

Складність зростає з рівнями (кожен пройдений міст = новий рівень):
мінімальна і максимальна швидкість скролу зростають на 10% за рівень,
тож на 10-му мосту гра вдвічі швидша, ніж на старті.

Декор: по берегах випадково ростуть дерева й кущі (суто візуальні, на
колізії не впливають — окрім того, що танки об дерева таки впираються).

Ігрове поле розтягується на всю висоту вікна браузера. При програші —
напис "ГРА ВСЬО" і фінальний рахунок, SPACE — рестарт.

## Технології

- **[Phaser 3](https://phaser.io/)** (3.90.0) — рушій для 2D-гри
- **Vanilla JavaScript**, без збірки (без webpack/vite/бандлерів) — просто
  відкривається в браузері
- Усі спрайти — процедурна піксель-арт графіка, намальована кодом через
  `Phaser.GameObjects.Graphics` (жодних зовнішніх картинок)
- Усі звуки — синтезовані на льоту через **Web Audio API** (жодних
  аудіофайлів)
- Звичайний HTML/CSS для каркасу сторінки
- **[Playwright](https://playwright.dev/)** + headless Chromium — для
  автоматизованих регресійних тестів у процесі розробки
- Без бекенду — повністю клієнтська гра, працює і локально (`file://`),
  і на GitHub Pages

## Як запустити локально

Просто відкрий `index.html` у браузері — жодних залежностей чи збірки не
треба.

Для тестів (опційно):

```bash
npm install
npx playwright install chromium
npm test
```
