# River Raid — клон класики на Phaser 3

🎮 **Грати онлайн:** https://esiteq.github.io/river-raid/

Браузерний ремейк культової аркади **River Raid** (Activision, 1982) —
керуєш літаком, летиш над річкою, збиваєш ворогів, підриваєш мости,
стежиш за пальним і не влітаєш у береги.

> Це фан-проєкт для навчання/експерименту, не пов'язаний з Activision і
> не має комерційної мети.

## Про проєкт

Ця гра — експеримент: наскільки швидко і наскільки грабельно (playable!)
можна зробити повноцінну аркадну гру, попросивши про це Claude. На базову
версію гри (терейн, що скролиться, керування літаком, вороги, паливо,
рахунок, мости) і кілька раундів доопрацювань та фіч поверх оригіналу
пішло приблизно **3 години** — від першого запиту "зроби браузерну версію
River Raid" до фінальної версії з усім переліченим нижче.

Увесь код, спрайти й звуки згенеровані — жодного зовнішнього арту чи
аудіофайлів, усе намальовано і синтезовано програмно.

## Керування

| Клавіша | Дія |
|---|---|
| `←` `→` | рух літака вліво/вправо (з нахилом "на крило") |
| `↑` | газ (пришвидшення) |
| `↓` | гальмо (майже до зупинки — потрібно для заправки) |
| `SPACE` | постріл / старт гри / рестарт після програшу |
| `P` / `ESC` | пауза |

## Функціонал

Базова механіка: рельєф річки, що процедурно генерується і плавно
(не рвано) вигинається; острови (прохід повз завжди гарантовано достатньо
широкий для літака); паливо, що витрачається залежно від швидкості й
поповнюється заправками (не більше трьох одночасно на екрані); три життя;
рахунок очок; мости, які можна підривати пострілом.

Вороги: гелікоптери (стріляють у бік гравця строго горизонтально, з
невеликим інтервалом між пострілами — як в оригіналі, без прицілювання по
вертикалі), кораблі та швидкі реактивні літаки (не стріляють, летять
горизонтально) — не більше трьох одиниць кожного типу одночасно на екрані,
щоб не рябіло. Берегові танки заїжджають до берега саме з того краю
екрана, де їхній берег, і стріляють лише припарковані біля води; постріли
завжди строго горизонтальні, без прицілювання по гравцю. Якщо на шляху
танка стоїть дерево — він упирається в нього і застрягає, не доїжджаючи й
не стріляючи (доки дерево не збити пострілом — тоді танк одразу їде далі).

Мости: якщо знищити міст разом із танком, який саме переїжджає по
ньому — рахунок потроюється (у танка є "втеча", тож треба встигнути).
Якщо танк ще не встиг втекти в момент вибуху — він гине разом з мостом.

Бонуси — веселкові повітряні кульки з літерою, яка позначає ефект:
`T` потрійний вогонь (вперед + вліво + вправо), `M` 50 пострілів двома
ракетами з самонаведенням (додатково до звичайного пострілу) — кількість
показується зверху екрана і зменшується на 1 за кожен постріл, а повторний
підбір `M` до вичерпання додає ще 50; `D` подвоєна частота стрільби,
`F` миттєва заправка на 100%, `N` знищує всіх ворогів на екрані (кульки не
займає), `X` додаткове життя. Активний бонус (крім `M`, який діє, доки не
скінчиться лічильник) тримається до підбору іншого або до втрати життя;
спецпостріли (ракети, бічні постріли) ігнорують кульки — збити їх можна
лише звичайним пострілом вперед.

Складність зростає з рівнями (кожен пройдений міст = новий рівень):
мінімальна і максимальна швидкість скролу зростають на 10% за рівень,
тож на 10-му мосту гра вдвічі швидша, ніж на старті.

Декор: по всій зеленій території берегів (а не тільки біля самої води)
випадково ростуть дерева й кущі — їх можна знищувати пострілом (дерево дає
30 очок, кущ 15), на прольот літака над ними це не впливає, а от танки об
них таки впираються, поки дерево не збити.

Уздовж води — смуга жовтого піску змінної ширини (0-32px): де-не-де ширша,
де-не-де вужча, місцями зникає зовсім, ніде не йде строго паралельно воді.
На самій воді час від часу з'являються короткі анімовані сплески/брижі.

Русло річки плавно, але помітно звивається — берег ніколи не йде довго
прямою лінією.

Ігрове поле розтягується на всю висоту вікна браузера. При програші —
напис "ГРА ВСЬО" і фінальний рахунок, SPACE — рестарт.

Вибухи (збитий ворог, підірваний міст тощо) плавно "ростуть" від маленького
розміру до повного і так само плавно зменшуються назад, безперервно
обертаючись за годинниковою стрілкою.

## Технології

- **[Phaser 3](https://phaser.io/)** (3.90.0) — рушій для 2D-гри
- **Vanilla JavaScript**, без збірки (без webpack/vite/бандлерів)
- Більшість спрайтів — процедурна піксель-арт графіка, намальована кодом
  через `Phaser.GameObjects.Graphics` (жодних зовнішніх файлів); літак
  гравця, танк, гелікоптер, реактивний літак-ворог, корабель, заправка,
  вибух, дерева/кущі на березі й ракета самонаведення — готові іконки,
  окремі PNG-файли в `assets/`, заздалегідь відмасштабовані рівно до
  розміру показу в грі
- Влучання пострілом по цих іконках перевіряється по реальних непрозорих
  пікселях картинки (альфа-маска, побудована один раз при завантаженні), а
  не прямокутником навколо центру — постріл повз видиму частину іконки не
  зараховується як влучання
- Усі звуки — синтезовані на льоту через **Web Audio API** (жодних
  аудіофайлів)
- Звичайний HTML/CSS для каркасу сторінки
- **[Playwright](https://playwright.dev/)** + headless Chromium — для
  автоматизованих регресійних тестів у процесі розробки
- Без бекенду — повністю клієнтська гра, але (через іконки в `assets/`)
  потребує локального http-сервера для запуску — просто подвійний клік по
  `index.html` (`file://`) більше не працює; на GitHub Pages все як завжди,
  бо там і так усе віддається по http

## Як запустити локально

Гра вантажить іконки з `assets/` через `this.load.image()` (Phaser робить
це через XHR), а браузери блокують такі запити до `file://` — тому просто
відкрити `index.html` подвійним кліком більше НЕ вийде, потрібен локальний
http-сервер:

```bash
npm install    # лише щоб мати npm-скрипти; сам сервер без залежностей
npm start      # підніме гру на http://localhost:8080/
```

Відкрий адресу, яку виведе `npm start`, у браузері. Підійде й будь-який
інший статичний http-сервер (`npx http-server`, `python3 -m http.server`
тощо) — головне, щоб файли роздавались саме по `http://`, а не `file://`.

Для тестів:

```bash
npx playwright install chromium   # один раз, якщо Chromium ще не стоїть
npm test
```

(тести самі піднімають свій тимчасовий сервер на кожен запуск, окремий
`npm start` для них не потрібен).

## Структура проєкту

```
index.html        — HTML-каркас
game.css           — стилі сторінки
game.js            — весь ігровий код (константи, сцени, логіка)
phaser.min.js       — бібліотека Phaser 3.90.0
assets/             — PNG-іконки (танк/гелікоптер/куля/гравець/літак/
                       корабель/заправка/вибух/дерева/кущі/ракета
                       самонаведення), обов'язкові для запуску
serve.js            — мінімальний http-сервер без залежностей (npm start)
tests/              — регресійні Playwright-тести
CLAUDE.md           — детальні технічні нотатки для розробки з Claude Code
package.json        — playwright як devDependency; npm start піднімає гру,
                       npm test запускає тести
```

Детальний опис архітектури (модель скролу рельєфу, система бонусів,
логіка танків тощо) — у [`CLAUDE.md`](./CLAUDE.md).
